Shallow copy v/s deep copy :: 

Shallow Copy :: 

=> It is like creating a new list . But both the new list and the existing list points to the same elements 
   So any change in any of the list will affect the items in both the lists

Deep Copy ::

=> It is like creating a new list with completely new items inside .
=> SO if you change anything in the copied list , it will not affect the existng list .


=> Note :: 

Integers are immutable → every time you “change” them, Python makes a new object.

The same is true for strings, floats, tuples, booleans.

=> Merging 2 dictionaries 

   dict1.update(dict2)
